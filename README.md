# parser-2gis (Rust)

Порт [interlark/parser-2gis](https://github.com/interlark/parser-2gis) на Rust + фильтры для поиска лидов:
«нет сайта», «нет Instagram / WhatsApp», «от N отзывов», рейтинг, обязательный телефон.

Работает так же, как оригинал: запускает браузер, кликает по организациям в выдаче
и перехватывает JSON карточки (`catalog.api.2gis.*/items/byid`) через DevTools Protocol.
Нужен любой Chromium-браузер: Chrome, Edge (есть в каждой Windows 10/11) или Яндекс.Браузер —
программа находит их сама.

## Windows

Запустите `parser-2gis.exe` двойным кликом — откроется окно:

1. **Где искать** — город из списка (поиск по названию) или «Вся страна» (первый пункт под названием страны —
   пройдёт по всем городам 2GIS этой страны) и что ищем. Несколько запросов через запятую
   («барбершоп, салон красоты») пройдут по очереди в один файл. Или вкладка «Свои ссылки» — вставить URL из 2GIS.
2. **Фильтры** — без сайта / без Instagram / без WhatsApp, только с телефоном, отзывы от–до, рейтинг,
   **один филиал от сети** и **язык названия** (см. ниже).
3. **Сохранение** — Excel, CSV или JSON и папка (по умолчанию «Документы\2GIS Лиды»).
   Имя файла создаётся само: `барбершоп_Костанай_2026-10-31_23-30.xlsx`.
4. **Начать поиск**. Найденные организации сразу появляются в таблице: клик по названию открывает
   карточку в 2GIS, клик по телефону копирует его. «Остановить» сохраняет всё, что уже собрано.

Настройки запоминаются между запусками. Если 2GIS перестал отдавать данные — включите
«Дополнительно → Показывать окно браузера».

Командная строка тоже работает: `parser-2gis.exe --help`.

## Сборка

```bash
cargo build --release                       # под текущую ОС
# под Windows из Linux (нужны zig и cargo-zigbuild):
cargo zigbuild --release --target x86_64-pc-windows-gnu
```

## Командная строка — примеры

```bash
# Барбершопы без сайта, от 10 отзывов → Excel
parser-2gis -i 'https://2gis.kz/kostanay/search/барбершоп' -o leads.xlsx \
  --no-website --min-reviews 10

# Нет НИ Instagram, НИ WhatsApp
parser-2gis -i URL -o out.csv --no-instagram --no-whatsapp

# Нет Instagram ИЛИ нет WhatsApp (хотя бы одного), телефон обязателен
parser-2gis -i URL -o out.csv --no-instagram --no-whatsapp --without-mode any --with phone

# Без ссылок: по всему Казахстану, без казахских названий
parser-2gis -q барбершоп -q "мужская парикмахерская" --country kz --lang not-kazakh --no-website -o kz.xlsx

# Несколько URL из файла, скрытый браузер
parser-2gis --urls-file urls.txt -o all.json --headless
```

## Фильтры

| Флаг | Что делает |
|---|---|
| `--no-website` | только без сайта |
| `--no-instagram` | только без Instagram |
| `--no-whatsapp` | только без WhatsApp |
| `--without KIND,...` | без любых контактов из списка: `website, instagram, whatsapp, telegram, vkontakte, facebook, viber, youtube, phone, email` |
| `--without-mode all\|any` | `all` (по умолчанию) — нет ни одного из перечисленных; `any` — нет хотя бы одного |
| `--with KIND,...` | эти контакты обязательны (например `--with phone`) |
| `--min-reviews N` / `--max-reviews N` | количество отзывов |
| `--min-rating X` / `--max-rating X` | рейтинг (без рейтинга не проходит `--min-rating`) |
| `--strict-website` | см. ниже |
| `--include-non-firms` | см. ниже |
| `--lang any\|not-kazakh\|russian\|kazakh` | язык названия |
| `--all-branches` | не отсеивать филиалы одной сети |

**Что считается сайтом.** В 2GIS в поле «Сайт» часто вписывают Instagram, wa.me или taplink.
По умолчанию такие ссылки сайтом **не** считаются: instagram.com засчитывается как Instagram,
wa.me — как WhatsApp, t.me — как Telegram, а taplink/linktr.ee и подобные игнорируются.
Флаг `--strict-website` отключает это поведение (любая ссылка в поле «Сайт» = сайт).

**Язык названия** (`--lang`): `not-kazakh` отсеивает организации, чьё название по-казахски
(казахские буквы ә ғ қ ң ө ұ ү һ і, слова вроде «шаштараз», «сұлулық», казахская латиница «Qazaq», «Shashtaraz»).
`russian` — только кириллица без казахских признаков, латиница тоже отсеивается. Это эвристика по названию:
бизнес владельца-казаха с названием «Barber King» или «Барбершоп Борода» пройдёт.
В таблице есть колонка «Язык названия» (рус / каз / лат).

**Филиалы.** По умолчанию от каждой сети пишется только один филиал (по ID организации в 2GIS),
а одна и та же точка, найденная по разным запросам или в разных городах, не дублируется.
`--all-branches` возвращает все филиалы. В таблице есть колонка «Филиалов в сети».

**Только организации.** Когда активен хоть один фильтр, остановки, улицы, парковки
и прочие не-организации отбрасываются (у них «нет сайта» по определению).
`--include-non-firms` возвращает их.

`--max-records N` считает именно записанные (прошедшие фильтр) записи с одного URL.
В конце печатается статистика: сколько просмотрено, записано и отсеяно.

## Остальные опции

Браузер: `--chrome-path`, `--headless`, `--show-images`, `--maximized`, `--memory-limit MB`,
`--chrome-arg ARG` (произвольный аргумент Chrome, можно несколько раз).

Парсер: `--max-records`, `--delay-ms` (пауза между кликами), `--no-skip-404`, `--gc-pages N`.

CSV/XLSX: `--columns-per-entity 1..5`, `--no-rubrics`, `--no-comments`, `--keep-empty-columns`,
`--keep-duplicates`, `--join-char`, `--encoding utf-8-sig|utf-8|cp1251`.

Полный список: `parser-2gis --help`.

## Отличия от оригинала

- Поддерживаются те же типы ссылок: поиск/рубрика (с пагинацией и переходом на `/page/N`),
  карточка фирмы `/firm/…`, «в здании» `/inside/…`. GUI и генератор ссылок не портированы — только CLI.
- Ctrl+C не теряет данные: файл корректно дописывается. Во время работы строки дублируются
  в `<имя>.partial.csv`, который удаляется после успешного завершения.
- Исправлен баг оригинала: контакты из второй группы карточки перетирали первую
  (Телефон 1 из группы 2 затирал Телефон 1 из группы 1).
- В колонке «Веб-сайт» реальный адрес сайта, а не редирект `link.2gis.*`.
- В XLSX рейтинг, отзывы и координаты — числами (можно сортировать), закреплена шапка, включён автофильтр.
- Счётчик незавершённых запросов учитывает и `fetch`, а не только XHR.
- Исправлен обрыв пагинации: в оригинале, если организация повторялась на двух страницах выдачи,
  парсер считал, что страница не обновилась, и останавливался.
